# 2026-04-07 — 뷰어 레이아웃 다듬기와 빠른 시작 보강

## 요약

이번 변경은 임베디드 뷰어가 실제 사용 환경에서 더 균형 있게 보이도록 레이아웃을 다듬고, README에 설치 직후 바로 따라 할 수 있는 빠른 시작과 첫 실행 가이드를 추가한 작업입니다.

## 무엇이 달라졌는가

- 뷰어를 전체 화면에 무조건 늘리는 대신, 읽기 좋은 폭과 더 균형 잡힌 사이드바/본문 비율을 갖도록 조정했습니다.
- 짧은 파일을 볼 때도 본문 영역이 과하게 비어 보이지 않도록 상태 패널과 콘텐츠 패널 구조를 다듬었습니다.
- 로딩, 빈 상태, 오류 상태를 더 명확한 본문 상태 메시지로 보여주도록 정리했습니다.
- README에 30초 빠른 시작, 수동 URL 열기, `Ctrl+C` 종료, 로컬 API 확인 흐름을 추가했습니다.

## 왜 필요한가

- 이전 버전은 기능은 단순했지만, 실제 브라우저에서는 본문 영역이 지나치게 커 보이고 전체 레이아웃이 덜 다듬어진 인상을 줄 수 있었습니다.
- 첫 사용자도 설치 후 무엇을 실행하고 어떤 출력이 정상인지 바로 따라갈 수 있도록 README를 더 실용적인 순서로 보강할 필요가 있었습니다.
