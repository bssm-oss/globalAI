# 2026-04-06 — 컴팩트 뷰어와 사용법 보강

## 요약

이번 변경은 `globalAI`의 임베디드 뷰어를 더 컴팩트하고 단순한 방향으로 정리하고, README에 실제 사용 흐름을 바로 이해할 수 있는 사용법을 보강한 작업입니다.

## 무엇이 달라졌는가

- 뷰어 UI를 더 밀도 높고 단순한 레이아웃으로 정리했습니다.
- 기존의 글로시한 카드, 큰 반경, 그림자 중심 스타일 대신 평평하고 절제된 단색 계층을 사용하도록 바꿨습니다.
- 소스 목록과 본문 뷰의 정보 구조를 더 단순하게 다듬어, 클릭해야 할 것과 읽어야 할 것에 집중하도록 했습니다.
- README에 설치 확인, 첫 실행, 뷰어에서 보게 되는 것, 빈 상태, 로컬 API 사용법을 추가했습니다.

## 왜 필요한가

- 제품의 핵심 흐름은 “소스를 선택하고 본문을 읽는 것”인데, 기존 UI는 이 단순한 흐름에 비해 시각적 층위와 장식이 많았습니다.
- 처음 사용하는 사용자는 설치 이후 무엇을 실행해야 하는지, 뷰어가 어떻게 열리는지, 아무 것도 나오지 않을 때 무엇을 확인해야 하는지 README만으로는 충분히 알기 어려웠습니다.

## 검증 근거

- `go test ./...`
- `go build ./cmd/globalai`
- `bash scripts/functional_smoke.sh`
- 샘플 소스로 `globalai web --no-open --addr 127.0.0.1:0` 실행
- `/api/sources` 응답 확인
- 실제 브라우저 스냅샷으로 컴팩트 UI 렌더링 확인
